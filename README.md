# Git Task Counter Lab

A small browser application for teaching Git, GitHub, pull requests, merge conflicts, code review, and GitHub Actions.

## Requirements

- Node.js 22 or newer
- Python 3
- Git

## Run the project

```bash
npm install
npm start
```

Open `http://localhost:5173`.

## Run tests

```bash
npm test
```

## Current features

- Add tasks
- Mark tasks as completed
- Delete tasks
- Count total, completed, and remaining tasks
- Save tasks in browser local storage
